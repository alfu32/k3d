the code repository is publicly  available on github : https://github.com/alfu32/k3d

the application is multiplatform:
- portable mac,linux,windows bundles,
- msix build ( available also through microsoft app store )
- ubuntu snap on snapcraft.io
- android aab available through google playstore - plugins and mcp server not (yet) available on tablets

the modeling is done more or less in direct mode , basically the user draws construction lines ( segments ) and faces.

it comes however with:
- some powerful mesh construction tools,
- prototyping ( object definitions/prototypes ), the prototypes have elements of graphical programming ( smart hotspots that perform operations on the selected prototype geometry )
- xrefs : external references to other model files
- plugins host and plugins manager
- a repl terminal that allows the user to construct things through text commands or to consult performance and model statistics.
- a rich collection of exporters and importers
- drafting helpers ( axial and planar grids, snapping on object points )
- a built in mcp server for interfacing with LLMs
- complete privacy and ownership over your models and activities ( no data whatsoever is collected)
