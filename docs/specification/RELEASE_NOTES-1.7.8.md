# Release Notes 1.7.8

## Changes since 1.7.3
- Added a Lighting panel with sliders to adjust shadow, directional, ambient, and specular values live; panel toggled via a toolbar button.
- Selection window behavior refined: left-to-right selects contained elements, right-to-left selects intersecting elements; Shift adds and Ctrl removes.
- Selection window rendering now switches to dashed outline for right-to-left drags.
- Toolbar uses icon atlas entries from `assets/icons.png` and `assets/icons.mapping.csv`, including the Lighting action icon.
- UI polish: status bar and selection info panels use a dark gray background; toolbar buttons keep white backgrounds with black text and hover-only labels.
