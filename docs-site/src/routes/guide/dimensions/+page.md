# Dimensions and Numeric Input

Octodraw includes linear dimensions, unit settings, grid spacing, snap radius, and numeric input for active tools.

## Dimensions

Use the Linear Dimension tool to annotate distances in the model. Dimension entities are saved with model files and can be included in selection counts.

## Units and Model Settings

The Model Settings panel controls unit name, unit size, grid spacing, snap radius, and walkthrough tuning. Current files persist unit and grid values with the model snapshot.

## Numeric Input

- `Ctrl+N`: show numeric input popup at the cursor.
- `0-9`, `.`, and `-`: direct numeric input while a tool is active.
- `Enter`: commit current numeric input.
- `Backspace`: clear or edit the active numeric buffer depending on tool state.
