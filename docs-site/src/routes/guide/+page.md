# Guide

This guide is the user-facing path through Octodraw. It condenses the existing manual chapters into focused pages for installing, navigating, drawing, selecting, snapping, editing, using objects, configuring lighting, and managing files.

## Recommended Order

1. [Install](./install/) and launch the desktop app.
2. Learn the [interface](./interface/) and [navigation](./navigation/).
3. Practice [selection](./selection/) and [snapping](./snapping/).
4. Use [drawing tools](./drawing-tools/) to create edges and faces.
5. Use [modify tools](./modify-tools/) to transform or extrude geometry.
6. Use [objects](./objects/) to isolate reusable groups and instances.
7. Save, recover, and export through [files](./files/).

## Current Status

Octodraw is active and evolving. Some workflows are implemented, some are partial, and command IDs should be verified with the current build when automation depends on them. User documentation should stay accurate rather than describing planned CAD features as complete.
