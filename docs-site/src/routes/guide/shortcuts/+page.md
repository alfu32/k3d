# Shortcuts

This page summarizes the current shortcut docs. Validate shortcuts against the active build before using them in automation.

## General

- `Ctrl+Shift+P`: command palette.
- `Esc`: cancel active tool, clear selection, clear guides, or exit object edit depending on context.
- `Delete`: delete selection.
- `Ctrl+Z`: undo.
- `Ctrl+Y` or `Ctrl+Shift+Z`: redo.

## Camera

- Right mouse drag: orbit.
- Shift + right mouse drag: pan.
- Mouse wheel: zoom.

## Tool Cycles

- `L`: construction tool cycle.
- `D`: dimension/text cycle.
- `O`: offset, Push/Pull, Extrude Swipe, and section cycle.
- `M`: Move, Rotate, Scale, Stretch, and copy-array cycle.

## Guides and Objects

- `G`: add grid guide at current snap.
- `T`: add axis guide at current snap.
- `Ctrl+G`: group selection.
- `Ctrl+Shift+G`: ungroup.
- `Ctrl+O`: create object prototype from selection.
