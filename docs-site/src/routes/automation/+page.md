# Automation

Automation documentation covers local MCP workflows, Codex task hygiene, generated reference strategy, screenshot production, and QA checks.

MCP is both documentation subject matter and a documentation production interface. Use it locally to validate command IDs, generate deterministic scenes, capture real screenshots, and refresh reference material. Do not make public browser tutorials or GitHub Pages deployment depend on a live desktop MCP server.
