# Octodraw-Free

## Pangalan ng produkto

Octodraw-Free

## Paglalarawan

Ang Octodraw-Free ay isang direktang 3D sketching at modeling workspace para gawing nae-edit na geometry ang mga ideya. Gumuhit ng mga linya at patag na mukha, pagkatapos ay gamitin ang mga tool para i-push at i-pull ang mga solid, ilipat, paikutin, i-scale, i-stretch, kulayan, at maglagay ng mga object.

Magtrabaho nang eksakto gamit ang snapping sa grid, endpoint, midpoint, linya, mukha, at guide. Gumamit ng click, window, crossing, at volume selection, gumawa ng grid at axis guide, at maglagay ng numeric value para sa aktibong tool. Pinapadali ng object prototype at instance ang pag-edit at pag-uulit ng mga bahagi ng disenyo.

Kasama sa Octodraw-Free ang Solid Union, Solid Intersection, Solid Subtraction, at Cut Objects para sa mesh workflow sa antas ng object. Ang Random Offset, Random Surface Array, Planar Regularize, at Surface Remesh ay tumutulong gumawa ng kontroladong variation, magkalat ng detalye sa ibabaw, at mag-ayos o bumuo muli ng angkop na mesh patch.

May mga panel para sa selection, object information, objects, model settings, lighting, plugins, at command palette. Tinutulungan ka ng real-time lighting, ambient at specular control, at shadows na suriin ang modelo habang nagtatrabaho.

Mag-save ng nae-edit na OCTD model at magbukas ng lumang K3D file. May autosave para sa pang-araw-araw na trabaho, habang ang built-in Groovy developer console at plugin system ay nagbibigay ng interactive na workspace para sa advanced users. Sinusuportahan ng local MCP automation ang mga command, scene inspection, camera control, at capture workflow.

## Ano ang bago

- Maaari nang magkalat ang Random Surface Array ng napiling payload geometry sa mga napiling mukha, na may control sa bilang, surface-normal alignment, scale variation, at rotation variation.
- Idinagdag ang Planar Regularize at Surface Remesh para bumuo muli ng angkop na open patch bilang regular triangle grid.
- Pinahusay ang Random Offset para sa connected vertices, selected segments, at face boundaries.
- Pinalawak ang fuzzy-tool settings at command-palette access.
- Pinahusay ang Linux at Snap packaging, kasama ang developer console launch at mas ligtas na Save As.
