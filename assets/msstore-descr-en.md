# Octodraw-Free

## Product name

Octodraw-Free

## Description

Octodraw-Free is a direct 3D sketching and modeling workspace for turning ideas into editable geometry. Draw edges and planar faces, then use familiar tool-driven workflows to push and pull solids, move, rotate, scale, stretch, paint, and place objects.

Work precisely with grid, endpoint, midpoint, line, face, and guide snapping. Use click, window, crossing, and volume selection, create grid and axis guides, and enter numeric values for active tools. Reusable object prototypes and instances make repeated design elements easy to edit and place.

Octodraw-Free includes Solid Union, Solid Intersection, Solid Subtraction, and Cut Objects for object-level mesh workflows. Random Offset, Random Surface Array, Planar Regularize, and Surface Remesh help create controlled variation, distribute detail over surfaces, and repair or rebuild suitable mesh patches.

The interface includes selection, object information, objects, model settings, lighting, plugin, and command-palette panels. Real-time lighting, ambient and specular controls, and shadows help you inspect a model as you work.

Save editable .octd models, open legacy .k3d files, and rely on autosave for everyday work. The built-in Groovy developer console and plugin system provide an interactive workspace for power users. Local MCP automation supports deterministic commands, camera control, scene inspection, and capture workflows.

Octodraw-Free is built for desktop use and also powers Android and embeddable WebGL experiences.

## What's new

- Random Surface Array now distributes selected payload geometry over selected faces with configurable copy count, surface-normal alignment, scale variation, and rotation variation.
- Added Planar Regularize and Surface Remesh workflows for rebuilding suitable open patches as regular triangle grids.
- Improved Random Offset behavior for connected vertices, selected segments, and face boundaries.
- Expanded fuzzy-tool settings and command-palette access for repeatable modeling workflows.
- Improved Linux and Snap packaging, including the developer console launch and safer Save As behavior.
