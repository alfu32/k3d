# Octodraw-Free

## ਉਤਪਾਦ ਦਾ ਨਾਮ

Octodraw-Free

## ਵੇਰਵਾ

Octodraw-Free ਇੱਕ direct 3D sketching ਅਤੇ modeling workspace ਹੈ ਜੋ ਵਿਚਾਰਾਂ ਨੂੰ ਸੋਧਣ ਯੋਗ geometry ਵਿੱਚ ਬਦਲਣ ਲਈ ਬਣਾਇਆ ਗਿਆ ਹੈ। Edges ਅਤੇ planar faces ਬਣਾਓ, ਫਿਰ solids ਨੂੰ push ਅਤੇ pull ਕਰਨ, move, rotate, scale, stretch, paint ਅਤੇ objects place ਕਰਨ ਵਾਲੇ tools ਵਰਤੋ।

Grid, endpoint, midpoint, line, face ਅਤੇ guide snapping ਨਾਲ ਸਹੀ ਕੰਮ ਕਰੋ। Click, window, crossing ਅਤੇ volume selection ਵਰਤੋ, grid ਅਤੇ axis guides ਬਣਾਓ ਅਤੇ active tools ਲਈ numeric values ਦਿਓ। Reusable object prototypes ਅਤੇ instances ਦੁਹਰਾਏ ਜਾਣ ਵਾਲੇ design elements ਨੂੰ ਆਸਾਨੀ ਨਾਲ ਸੋਧਣ ਅਤੇ ਰੱਖਣ ਵਿੱਚ ਮਦਦ ਕਰਦੇ ਹਨ।

Octodraw-Free ਵਿੱਚ object-level mesh workflows ਲਈ Solid Union, Solid Intersection, Solid Subtraction ਅਤੇ Cut Objects ਹਨ। Random Offset, Random Surface Array, Planar Regularize ਅਤੇ Surface Remesh ਨਾਲ ਨਿਯੰਤਰਿਤ variation ਬਣਾਓ, surface ਉੱਤੇ detail ਵੰਡੋ ਅਤੇ ਉਚਿਤ mesh patches ਨੂੰ ਸੁਧਾਰੋ ਜਾਂ ਦੁਬਾਰਾ ਬਣਾਓ।

Interface ਵਿੱਚ selection, object information, objects, model settings, lighting, plugin ਅਤੇ command-palette panels ਹਨ। Real-time lighting, ambient ਅਤੇ specular controls ਅਤੇ shadows ਨਾਲ ਕੰਮ ਕਰਦੇ ਸਮੇਂ model ਦੀ ਜਾਂਚ ਕਰੋ।

ਸੋਧਣ ਯੋਗ OCTD models save ਕਰੋ ਅਤੇ ਪੁਰਾਣੀਆਂ K3D files ਖੋਲ੍ਹੋ। Autosave ਰੋਜ਼ਾਨਾ ਕੰਮ ਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖਦਾ ਹੈ। Built-in Groovy developer console ਅਤੇ plugin system advanced users ਲਈ interactive workspace ਦਿੰਦੇ ਹਨ, ਜਦਕਿ local MCP automation commands, scene inspection, camera control ਅਤੇ captures ਨੂੰ support ਕਰਦੀ ਹੈ।

## ਨਵਾਂ ਕੀ ਹੈ

- Random Surface Array ਹੁਣ selected payload geometry ਨੂੰ selected faces ਉੱਤੇ ਵੰਡਦਾ ਹੈ ਅਤੇ copy count, surface-normal alignment, scale variation ਅਤੇ rotation variation ਲਈ settings ਦਿੰਦਾ ਹੈ।
- ਉਚਿਤ open patches ਨੂੰ regular triangle grid ਵਜੋਂ ਦੁਬਾਰਾ ਬਣਾਉਣ ਲਈ Planar Regularize ਅਤੇ Surface Remesh ਜੋੜੇ ਗਏ ਹਨ।
- Connected vertices, selected segments ਅਤੇ face boundaries ਲਈ Random Offset ਨੂੰ ਸੁਧਾਰਿਆ ਗਿਆ ਹੈ।
- Fuzzy-tool settings ਅਤੇ command-palette access ਨੂੰ ਵਧਾਇਆ ਗਿਆ ਹੈ।
- Linux ਅਤੇ Snap packaging ਸੁਧਾਰੀ ਗਈ ਹੈ, ਜਿਸ ਵਿੱਚ developer console launch ਅਤੇ ਹੋਰ ਸੁਰੱਖਿਅਤ Save As ਸ਼ਾਮਲ ਹਨ।
