# Octodraw-Free

## پراڊڪٽ جو نالو

Octodraw-Free

## وضاحت

Octodraw-Free هڪ direct 3D sketching ۽ modeling workspace آهي، جيڪو خيالن کي editable geometry ۾ بدلڻ لاءِ ٺاهيو ويو آهي. Edges ۽ planar faces ٺاهيو، پوءِ solids کي push ۽ pull ڪرڻ، move، rotate، scale، stretch، paint ۽ objects place ڪرڻ وارا tools استعمال ڪريو.

Grid، endpoint، midpoint، line، face ۽ guide snapping سان درست ڪم ڪريو. Click، window، crossing ۽ volume selection استعمال ڪريو، grid ۽ axis guides ٺاهيو، ۽ active tools لاءِ numeric values داخل ڪريو. Reusable object prototypes ۽ instances بار بار استعمال ٿيندڙ design elements کي آساني سان edit ۽ place ڪرڻ ڏين ٿا.

Octodraw-Free ۾ object-level mesh workflows لاءِ Solid Union، Solid Intersection، Solid Subtraction ۽ Cut Objects شامل آهن. Random Offset، Random Surface Array، Planar Regularize ۽ Surface Remesh سان controlled variation ٺاهيو، surface تي detail ورهايو ۽ مناسب mesh patches کي بهتر يا ٻيهر ٺاهيو.

Interface ۾ selection، object information، objects، model settings، lighting، plugin ۽ command-palette panels شامل آهن. Real-time lighting، ambient ۽ specular controls ۽ shadows سان ڪم دوران model کي جانچيو.

Editable OCTD models save ڪريو ۽ پراڻيون K3D files کوليو. Autosave روزاني ڪم کي محفوظ رکڻ ۾ مدد ڪري ٿو. Built-in Groovy developer console ۽ plugin system advanced users لاءِ interactive workspace مهيا ڪن ٿا، جڏهن ته local MCP automation commands، scene inspection، camera control ۽ captures کي support ڪري ٿي.

## نئون ڇا آهي

- Random Surface Array هاڻي selected payload geometry کي selected faces تي ورهائي ٿو، جنهن ۾ copy count، surface-normal alignment، scale variation ۽ rotation variation جا اختيار آهن.
- مناسب open patches کي regular triangle grid طور ٻيهر ٺاهڻ لاءِ Planar Regularize ۽ Surface Remesh شامل ڪيا ويا آهن.
- Connected vertices، selected segments ۽ face boundaries لاءِ Random Offset بهتر ڪيو ويو آهي.
- Fuzzy-tool settings ۽ command-palette access کي وڌايو ويو آهي.
- Linux ۽ Snap packaging بهتر ڪئي وئي آهي، جنهن ۾ developer console launch ۽ وڌيڪ محفوظ Save As شامل آهن.
