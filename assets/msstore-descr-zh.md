# Octodraw-Free

## 产品名称

Octodraw-Free

## 产品描述

Octodraw-Free 是一个直接进行三维草图和建模的工作空间，帮助你把想法转换为可编辑的几何体。绘制边线和平面，然后使用推拉、移动、旋转、缩放、拉伸、涂色和放置对象等工具完成设计。

你可以使用网格、端点、中点、线、面和辅助线捕捉来提高精度，也可以使用点击、框选、交叉选择和体积选择。创建网格辅助线和轴向辅助线，并为当前工具输入数值。对象原型和实例适合重复使用和编辑设计元素。

Octodraw-Free 提供实体并集、实体交集、实体差集和对象切割，用于对象级网格工作流。随机偏移、随机表面阵列、平面规则化和表面重网格工具可以生成受控变化、在表面分布细节，并重建适合的网格区域。

界面包含选择、对象信息、对象、模型设置、灯光、插件和命令面板。实时灯光、环境光、高光和阴影控制帮助你在建模过程中检查结果。

保存可编辑的 OCTD 模型，也可以打开旧版 K3D 文件；自动保存帮助保护日常工作。内置 Groovy 开发控制台和插件系统为高级用户提供交互式工作空间，本地 MCP 自动化则支持确定性命令、场景检查、相机控制和截图流程。

## 最新内容

- 随机表面阵列现在可以把选定的载荷几何体分布到选定的面上，并控制复制数量、表面法线对齐、缩放变化和旋转变化。
- 新增平面规则化和表面重网格，用于把合适的开放区域重建为规则三角网格。
- 改进随机偏移对连接顶点、选定线段和面边界的处理。
- 扩展随机工具设置，并改善从命令面板访问这些工具的方式。
- 改进 Linux 和 Snap 打包，包括开发控制台启动和“另存为”行为。

## 产品功能

- 直接创建边线、平面和实体
- 推拉、移动、旋转、缩放和拉伸
- 网格、端点、中点、线、面和辅助线捕捉
- 点击、框选、交叉选择和体积选择
- 可重复使用的对象原型与实例
- 实体并集、交集、差集和对象切割
- 随机偏移和随机表面阵列
- 平面规则化和表面重网格
- 实时灯光、阴影、尺寸和文字
- Groovy 开发控制台、插件和本地 MCP 自动化
