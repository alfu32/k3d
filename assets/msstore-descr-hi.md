# Octodraw-Free

## उत्पाद का नाम

Octodraw-Free

## विवरण

Octodraw-Free एक direct 3D sketching और modeling workspace है, जो विचारों को संपादन योग्य geometry में बदलने में मदद करता है। Edges और planar faces बनाएं, फिर solids को push और pull करने, move, rotate, scale, stretch, paint और objects place करने वाले टूल का उपयोग करें।

Grid, endpoint, midpoint, line, face और guide snapping से सटीक काम करें। Click, window, crossing और volume selection का उपयोग करें, grid और axis guides बनाएं और active tools में numeric values दर्ज करें। Reusable object prototypes और instances बार-बार उपयोग होने वाले design elements को आसानी से संपादित और रखने में मदद करते हैं।

Octodraw-Free में object-level mesh workflows के लिए Solid Union, Solid Intersection, Solid Subtraction और Cut Objects शामिल हैं। Random Offset, Random Surface Array, Planar Regularize और Surface Remesh से नियंत्रित variation बनाएं, surface पर detail फैलाएं और उपयुक्त mesh patches को सुधारें या दोबारा बनाएं।

Interface में selection, object information, objects, model settings, lighting, plugin और command-palette panels हैं। Real-time lighting, ambient और specular controls तथा shadows से काम करते समय model की जांच करें।

संपादन योग्य OCTD models save करें और पुराने K3D files खोलें। Autosave रोज़मर्रा के काम को सुरक्षित रखने में मदद करता है। Built-in Groovy developer console और plugin system advanced users के लिए interactive workspace देते हैं, जबकि local MCP automation commands, scene inspection, camera control और captures को support करता है।

## नया क्या है

- Random Surface Array अब selected payload geometry को selected faces पर वितरित करता है और copy count, surface-normal alignment, scale variation तथा rotation variation नियंत्रित करने देता है।
- उपयुक्त खुले patches को regular triangle grid में बनाने के लिए Planar Regularize और Surface Remesh जोड़े गए।
- Connected vertices, selected segments और face boundaries के लिए Random Offset behavior बेहतर किया गया।
- Fuzzy-tool settings और command-palette access का विस्तार किया गया।
- Linux और Snap packaging में सुधार, जिसमें developer console launch और अधिक सुरक्षित Save As शामिल हैं।
