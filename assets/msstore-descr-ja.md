# Octodraw-Free

## 製品名

Octodraw-Free

## 説明

Octodraw-Free は、アイデアを編集可能なジオメトリに変えるためのダイレクト 3D スケッチ・モデリング環境です。エッジや平面フェイスを描き、押し出し、移動、回転、拡大縮小、ストレッチ、ペイント、オブジェクト配置を行えます。

グリッド、端点、中点、線、面、ガイドへのスナップで正確に作業できます。クリック、ウィンドウ、交差、ボリューム選択を使い、グリッドや軸ガイドを作成し、アクティブなツールに数値を入力できます。オブジェクトのプロトタイプとインスタンスにより、繰り返し使う要素を簡単に編集・配置できます。

Solid Union、Solid Intersection、Solid Subtraction、Cut Objects を使ったオブジェクト単位のメッシュ処理に対応しています。Random Offset、Random Surface Array、Planar Regularize、Surface Remesh で、制御された変化の作成、表面へのディテール配置、適切なメッシュパッチの再構築ができます。

選択、オブジェクト情報、オブジェクト、モデル設定、ライティング、プラグイン、コマンドパレットのパネルを備えています。リアルタイム照明、環境光とスペキュラ設定、影によって、作業中のモデルを確認できます。

編集可能な OCTD モデルを保存し、旧 K3D ファイルを開けます。自動保存で日常の作業を保護できます。内蔵 Groovy 開発コンソールとプラグインシステムは上級ユーザー向けの対話環境を提供し、ローカル MCP 自動化はコマンド、シーン確認、カメラ操作、キャプチャを支援します。

## 新機能

- Random Surface Array が選択したジオメトリを選択した面へ分散し、コピー数、面法線への整列、スケール変化、回転変化を設定できるようになりました。
- 適切な開いたパッチを規則的な三角形グリッドへ再構築する Planar Regularize と Surface Remesh を追加しました。
- 接続頂点、選択セグメント、面の境界に対する Random Offset を改善しました。
- ファジーツール設定とコマンドパレットからのアクセスを拡張しました。
- 開発コンソールの起動と Save As を含む Linux および Snap パッケージを改善しました。

## 製品の機能

- エッジ、面、ソリッドのダイレクトモデリング
- Push/Pull、Move、Rotate、Scale、Stretch
- グリッド、端点、中点、線、面、ガイドへのスナップ
- クリック、ウィンドウ、交差、ボリューム選択
- 再利用可能なオブジェクトプロトタイプとインスタンス
- ソリッドの Union、Intersection、Subtraction、Cut
- Random Offset と Random Surface Array
- Planar Regularize と Surface Remesh
- リアルタイム照明、影、寸法、テキスト
- Groovy コンソール、プラグイン、ローカル MCP 自動化
